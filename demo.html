WYSIWYG HTML Editor

A pure JavaScript WYSIWYG editor with no external dependencies

Features

  • Pure JavaScript - No external dependencies
  • Drag and drop image support
  • Undo/Redo functionality (Ctrl+Z / Ctrl+Y)
  • Supports both HTML fragments and full documents
  • Custom templating system support
  • Full accessibility with ARIA labels and roles
  • Embeddable in any form with textarea or div
  • Keyboard shortcuts (Ctrl+B, Ctrl+I, Ctrl+U)
  • Rich text formatting (bold, italic, underline, headings, lists)
  • Image insertion and alignment
  • Link creation
  • HTML code view toggle

Demo 1: Basic Editor with Textarea

This example shows the editor embedded with a textarea element.

Try dragging and dropping an image into the editor below, or use the toolbar to format text!

HTML Output:


        


        

            const editor1 = new WYSIWYGEditor({
    target: '#editor1',
    placeholder: 'Start typing...',
    ariaLabel: 'Main content editor',
    ariaDescribedBy: 'editor-description',
    onChange: (html) => {
        document.getElementById('output1').textContent = html;
    }
});

Demo 4: Custom Image Upload Handler

        
Handle image uploads with custom logic (e.g., upload to server).


        


        

            
Upload Log:

            
Drag and drop an image to see the upload handler in action...

        


        

            const editor4 = new WYSIWYGEditor({
    target: '#editor4-container',
    onImageDrop: (file, callback) => {
        // Simulate upload to server
        const formData = new FormData();
        formData.append('image', file);
        
        // In real app, you would upload to server:
        // fetch('/upload', { method: 'POST', body: formData })
        //     .then(res => res.json())
        //     .then(data => callback(data.url));
        
        // For demo, we'll use FileReader
        const reader = new FileReader();
        reader.onload = (e) => {
            callback(e.target.result);
        };
        reader.readAsDataURL(file);
    }
});
        

    


    

        
API Reference

        
        
Constructor Options

        

            new WYSIWYGEditor({
    target: '#element',              // CSS selector or DOM element (required)
    toolbar: true,                   // Show toolbar (default: true)
    toolbarButtons: [...],           // Array of button names
    placeholder: 'Start typing...',  // Placeholder text
    maxHistorySize: 100,             // Max undo/redo history
    imageUploadHandler: fn,          // Custom image upload function
    onChange: fn,                    // Called when content changes
    onImageDrop: fn,                 // Called when image is dropped
    customTemplates: {},             // Custom template definitions
    allowFullDocument: true,         // Support full HTML documents
    ariaLabel: 'Rich text editor',   // ARIA label for accessibility
    ariaDescribedBy: 'desc-id'       // ARIA described-by ID
});
        


        
Methods

        

            editor.getHTML()              // Get HTML content
editor.setHTML(html)           // Set HTML content
editor.getDocument()           // Get full HTML document
editor.setDocument(html)       // Set full HTML document
editor.insertHTML(html)        // Insert HTML at cursor
editor.insertTemplate(name)    // Insert custom template
editor.undo()                  // Undo last change
editor.redo()                  // Redo last undone change
editor.destroy()               // Remove editor and restore target
